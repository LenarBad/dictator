# Установка Dictator на Mac

Нужен Mac с чипом **Apple** (M1, M2, M3, M4) и **macOS 12** или новее. Компьютеры на Intel пока не поддерживаются.

Готовое приложение лежит на GitHub: скачали zip, перетащили в «Программы», открыли. Node, Rust и Терминал не нужны.

Если на странице Releases ещё нет файла — его собирает GitHub после тега вида `v0.1.0`. Пока файла нет, можно [собрать из исходников](#сборка-из-исходников).

## 1. Скачайте zip

1. Откройте страницу [Releases](https://github.com/LenarBad/dictator/releases/latest).
2. Скачайте **Dictator-macos-aarch64.app.zip** (около 250 МБ: программа и модель распознавания вместе).
3. В «Загрузках» дважды щёлкните zip — появится **Dictator.app**.

## 2. Положите в «Программы»

Перетащите `Dictator.app` в папку **Программы** (`/Applications`).

Не оставляйте его в «Загрузках»: разрешения macOS привязаны к конкретному файлу.

## 3. Первый запуск (Gatekeeper)

Сборка подписана «ad-hoc»: у Dictator нет платного Apple Developer ID и нотаризации. Поэтому при первом запуске macOS покажет предупреждение — это ожидаемо.

На новых macOS окно часто выглядит так:

- заголовок **«Dictator» Not Opened** / **«Dictator» не открыто**;
- текст вроде *Apple could not verify “Dictator” is free of malware…*;
- кнопки **Done** / **Готово** и **Move to Trash** / **Переместить в Корзину**.

**Не нажимайте Move to Trash.** Нажмите **Done** / **Готово**, затем разрешите запуск одним из способов ниже.

### Способ A — через настройки (удобнее на новых macOS)

1. Откройте **Системные настройки → Конфиденциальность и безопасность**.
2. Прокрутите вниз до раздела про заблокированные приложения.
3. Нажмите **Всё равно открыть** / **Open Anyway** рядом с сообщением про Dictator.
4. Подтвердите (пароль или Touch ID). При необходимости ещё раз нажмите **Открыть**.

### Способ B — правый клик в Finder

1. В Finder откройте **Программы**.
2. Найдите **Dictator**.
3. **Правый клик** (или Control + клик) → **Открыть**.
4. В диалоге снова нажмите **Открыть** (не «Переместить в Корзину»).

После успешного запуска иконки в Dock **не будет**. Dictator живёт в **строке меню**, справа вверху, рядом с часами и Wi‑Fi.

Из Терминала тоже можно открыть:

```bash
open /Applications/Dictator.app
```

Если Gatekeeper ещё не разрешён, снова появится то же предупреждение — тогда снова способ A или B.

## 4. Разрешения

Dictator должен стоять в списках **как Dictator**, не Terminal.

1. Откройте **Системные настройки → Конфиденциальность и безопасность**.
2. **Микрофон** — включите Dictator.
3. **Универсальный доступ** — нажмите «+», выберите `/Applications/Dictator.app`.

Без микрофона запись не начнётся. Без универсального доступа текст попадёт в буфер, но не вставится в активное поле (тогда поможет Cmd+V).

Те же пункты есть в окне настроек Dictator (меню иконки → **Настройки…** → раздел «Разрешения»).

Если вы **обновили** приложение новым zip, подпись меняется. Удалите Dictator из «Универсального доступа» (кнопка «−») и добавьте `/Applications/Dictator.app` заново.

## 5. Как пользоваться

| Действие | Как |
|---|---|
| Начать / остановить запись | `Control + Shift + D` или пункт меню иконки |
| Настройки | Меню иконки → «Настройки…» |
| Выход | Меню иконки → «Выход» |

1. Поставьте курсор в любое текстовое поле (Заметки, браузер, мессенджер).
2. Нажмите хоткей, говорите по-русски, нажмите хоткей ещё раз.
3. Текст вставится в поле.

Иконка меняет вид: ожидание → запись → распознавание.

Не назначайте `Control + Пробел` — macOS забирает это сочетание на смену языка.

## FAQ

### Почему macOS пишет, что Apple не может проверить Dictator?

Релиз собран с ad-hoc подписью, без нотаризации Apple. Gatekeeper блокирует первый запуск у любых таких приложений. Это не диагноз «вредоносное ПО», а «разработчик Apple не известен». Разрешите запуск по [шагу 3](#3-первый-запуск-gatekeeper).

### В окне только Done и Move to Trash — куда жать «Открыть»?

На новых macOS кнопки «Открыть» в этом диалоге часто нет. Нажмите **Done** / **Готово**, затем **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Либо правый клик по приложению в «Программах» → **Открыть**.

### Безопасно ли открывать?

Исходники открыты в этом репозитории (MIT). Приложение не шлёт голос и текст в интернет после установки. Разрешение Gatekeeper — ваш выбор: вы доверяете сборке с GitHub Releases (или своей сборке из исходников).

У Dictator есть доступ к микрофону и (для вставки) к универсальному доступу — это нужно для диктовки. Уведомления могут показать начало фразы; полный текст остаётся в буфере. Threat model: [SECURITY.md](../SECURITY.md).

### Иконки нет в Dock и нигде не видно

Так и задумано: без иконки в Dock. Смотрите **правый верхний угол** экрана (строка меню). Если там пусто:

```bash
open /Applications/Dictator.app
```

### Хоткей не работает

Запись можно включить кликом по иконке в строке меню. Проверьте **Универсальный доступ**. Не используйте `Control + Пробел` — его забирает смена языка.

### Текст есть в буфере, но не вставляется в поле

Нажмите Cmd+V. Добавьте `/Applications/Dictator.app` в **Универсальный доступ**. Запускайте копию из «Программ», не из «Загрузок».

### После обновления вставка снова сломалась

Подпись бандла изменилась. Удалите Dictator из «Универсального доступа» и добавьте `/Applications/Dictator.app` заново.

### Как проверить, что вставка доверена системе?

Откройте файл `~/Library/Application Support/dictator/last-paste.log`. Нужны `trusted=true` и путь с `/Applications/Dictator.app`.

### Intel Mac / Windows / Linux?

Пока только Apple Silicon (M1 и новее). Windows и Linux планируются позже.

### На Releases нет zip

Подождите, пока GitHub Actions соберёт релиз после тега, или [соберите из исходников](#сборка-из-исходников).

## Удаление

1. Меню иконки → **Выход**.
2. Перетащите `/Applications/Dictator.app` в Корзину.
3. По желанию удалите настройки: папка `~/Library/Application Support/dictator`.
4. Уберите Dictator из списков микрофона и универсального доступа.
5. Если приложение аварийно завершилось во время распознавания, проверьте временную папку на файлы `dictator-*.wav` и удалите их.

Zip в «Загрузках» после установки не нужен.

## Сборка из исходников

Этот путь нужен, если на Releases ещё нет zip или вы меняете код. Понадобятся Терминал, инструменты Apple, Node и Rust. Сборка занимает **15–40 минут** и около **2 ГБ** места.

### 1. Откройте Терминал

1. Нажмите `Command (⌘) + Пробел` — откроется поиск Spotlight.
2. Наберите `Терминал` или `Terminal`.
3. Нажмите Enter.

Появится окно с текстом. Сюда вы будете **вставлять команды** и нажимать Enter. Команду можно скопировать целиком.

### 2. Инструменты компиляции Apple

```bash
xcode-select --install
```

Появится системное окно. Нажмите **Установить** / **Install** и дождитесь окончания. Если система пишет, что инструменты уже установлены — так и должно быть, идите дальше.

### 3. Homebrew

Homebrew — способ ставить программы одной командой. Проверьте, есть ли он:

```bash
brew --version
```

Если увидели номер версии (например `Homebrew 4.x`) — переходите к шагу 4.

Если `command not found` — установите:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Скрипт спросит пароль пользователя Mac (символы не отображаются — это нормально) и попросит нажать Enter. В конце он **сам напишет** две команды вида `echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile` — выполните их, затем:

```bash
brew --version
```

### 4. Node.js и Rust

```bash
brew install node rust
```

Проверка:

```bash
node --version
rustc --version
```

Должны появиться номера версий. Если нет — закройте Терминал, откройте снова и повторите `brew --version`.

### 5. Скачайте исходники Dictator

**Вариант А — с GitHub, без git.** На странице репозитория нажмите зелёную кнопку **Code → Download ZIP**. Распакуйте архив двойным щелчком. Папка обычно называется `dictator-main` и лежит в «Загрузках».

В Терминале:

```bash
cd ~/Downloads/dictator-main
```

Если папка называется иначе (например `dictator`), подставьте её имя.

**Вариант Б — через git** (если шаг 2 прошёл успешно, git уже есть):

```bash
cd ~
git clone https://github.com/LenarBad/dictator.git
cd dictator
```

### 6. Соберите и установите приложение

Из папки проекта:

```bash
cd desktop
npm install
npm run build:app
```

Первый запуск долгий: качается модель GigaAM и собирается программа. Не закрывайте Терминал. Когда всё готово, в конце будет путь `/Applications/Dictator.app`.

Откройте приложение:

```bash
open /Applications/Dictator.app
```

Дальше — [первый запуск](#3-первый-запуск-gatekeeper), [разрешения](#4-разрешения) и [использование](#5-как-пользоваться), как у готового zip.

**В Терминале красный текст при сборке.** Чаще всего не хватает шагов 2 или 4. Закройте Терминал, откройте заново, проверьте `node --version` и `rustc --version`, повторите шаг 6.

**`cd: no such file or directory`.** Вы не в той папке. В Finder откройте распакованный архив, перетащите папку в окно Терминала после слова `cd` и пробела, нажмите Enter.
