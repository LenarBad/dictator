# Установка Dictator

Нужен **Mac с чипом Apple** (M1–M4), **macOS 12+**, или **Windows 10 1809+ x64**. Intel Mac, Windows ARM и Linux пока не поддерживаются.

Готовые файлы на GitHub: скачали, поставили, открыли. Node, Rust и Терминал не нужны.

| Система | Файл | Куда |
|---|---|---|
| Mac | `Dictator-macos-aarch64.app.zip` (~250 МБ) | папка **Программы** |
| Windows | `Dictator-windows-x64.exe` (~250 МБ) | NSIS-установщик; zip — запасной портативный прогон |

Если на странице [Releases](https://github.com/LenarBad/dictator/releases/latest) ещё нет файла — его собирает GitHub после тега вида `v0.1.0`. Пока файла нет, на Mac можно [собрать из исходников](BUILD.md). Windows-установщик с Mac локально не собирают: [Actions](https://github.com/LenarBad/dictator/actions) → Release Windows.

## Mac

### 1. Скачайте zip

1. Откройте страницу [Releases](https://github.com/LenarBad/dictator/releases/latest).
2. Скачайте **Dictator-macos-aarch64.app.zip** (программа и модель распознавания вместе).
3. В «Загрузках» дважды щёлкните zip — появится **Dictator.app**.

### 2. Положите в «Программы»

Перетащите `Dictator.app` в папку **Программы** (`/Applications`).

Не оставляйте его в «Загрузках»: разрешения macOS привязаны к конкретному файлу.

### 3. Первый запуск (Gatekeeper)

Сборка подписана «ad-hoc»: у Dictator нет платного Apple Developer ID и нотаризации. Поэтому при первом запуске macOS покажет предупреждение — это ожидаемо.

На новых macOS окно часто выглядит так:

- заголовок **«Dictator» Not Opened** / **«Dictator» не открыто**;
- текст вроде *Apple could not verify “Dictator” is free of malware…*;
- кнопки **Done** / **Готово** и **Move to Trash** / **Переместить в Корзину**.

**Не нажимайте Move to Trash.** Нажмите **Done** / **Готово**, затем разрешите запуск одним из способов ниже.

#### Способ A — через настройки (удобнее на новых macOS)

1. Откройте **Системные настройки → Конфиденциальность и безопасность**.
2. Прокрутите вниз до раздела про заблокированные приложения.
3. Нажмите **Всё равно открыть** / **Open Anyway** рядом с сообщением про Dictator.
4. Подтвердите (пароль или Touch ID). При необходимости ещё раз нажмите **Открыть**.

#### Способ B — правый клик в Finder

1. В Finder откройте **Программы**.
2. Найдите **Dictator**.
3. **Правый клик** (или Control + клик) → **Открыть**.
4. В диалоге снова нажмите **Открыть** (не «Переместить в Корзину»).

После успешного запуска иконки в Dock **не будет**. Dictator живёт в **строке меню**, справа вверху, рядом с часами и Wi‑Fi.

Из Терминала тоже можно открыть:

```bash
open /Applications/Dictator.app
```

Если Gatekeeper ещё не разрешён, снова появится то же предупреждение — тогда снова способ A или B.

### 4. Разрешения

Dictator должен стоять в списках **как Dictator**, не Terminal.

1. Откройте **Системные настройки → Конфиденциальность и безопасность**.
2. **Микрофон** — включите Dictator.
3. **Универсальный доступ** — нажмите «+», выберите `/Applications/Dictator.app`.

Без микрофона запись не начнётся. Без универсального доступа текст попадёт в буфер, но не вставится в активное поле (тогда поможет Cmd+V).

Те же пункты есть в окне настроек Dictator (меню иконки → **Настройки…**). Раздел «Разрешения» виден, пока чего-то не хватает, и исчезает, когда оба доступа выданы.

Если вы **обновили** приложение новым zip, подпись меняется. Удалите Dictator из «Универсального доступа» (кнопка «−») и добавьте `/Applications/Dictator.app` заново.

## Windows

На тестовом ПК не нужны Visual Studio, Rust и Node: ставится готовый exe с Releases.

### 1. Скачайте установщик

1. Откройте [Releases](https://github.com/LenarBad/dictator/releases/latest).
2. Скачайте **Dictator-windows-x64.exe**. Запасной файл — `Dictator-windows-x64.zip` (папка с программой и моделью, без установщика).
3. Запустите exe. NSIS при необходимости подтянет **WebView2 Evergreen**.

### 2. SmartScreen

Подписи Authenticode нет, поэтому Windows покажет предупреждение — это ожидаемо, как Gatekeeper на Mac.

1. **Подробнее**.
2. **Выполнить в любом случае**.

Не путайте с «не запускать». Исходники открыты; доверие — к zip/exe с GitHub Releases или к своей сборке.

### 3. Микрофон

**Параметры → Конфиденциальность и безопасность → Микрофон** — разрешите Dictator.

Универсального доступа на Windows нет: вставка идёт через буфер и Ctrl+V. Строка «Универсальный доступ» в настройках Dictator скрыта.

После запуска иконки на панели задач **не будет**. Dictator в **трее** (системный лоток, обычно справа внизу, иногда за стрелкой «скрытые значки»).

### 4. Если текст не вставился

Нажмите Ctrl+V. Окна, запущенные **от имени администратора**, из обычного Dictator не примут SendInput — фраза останется в буфере.

## 5. Как пользоваться

| Действие | Как |
|---|---|
| Начать / остановить запись | `Control + Shift + D`, пункт меню иконки или клик по индикатору сверху |
| Настройки | Меню иконки → «Настройки…» |
| Выход | Меню иконки → «Выход» |

1. Поставьте курсор в любое текстовое поле (Заметки, браузер, мессенджер, Блокнот).
2. Нажмите хоткей, говорите по-русски, нажмите хоткей ещё раз (или кликните по волне вверху экрана).
3. Текст вставится в поле.

Пока идёт запись, вверху экрана появляется индикатор с волной. Иконка в строке меню / трее тоже меняет вид: ожидание → запись → распознавание.

На Mac не назначайте `Control + Пробел` — система забирает это сочетание на смену языка.

## FAQ

### Почему macOS пишет, что Apple не может проверить Dictator?

Релиз собран с ad-hoc подписью, без нотаризации Apple. Gatekeeper блокирует первый запуск у любых таких приложений. Это не диагноз «вредоносное ПО», а «разработчик Apple не известен». Разрешите запуск по [шагу 3](#3-первый-запуск-gatekeeper).

### В окне только Done и Move to Trash — куда жать «Открыть»?

На новых macOS кнопки «Открыть» в этом диалоге часто нет. Нажмите **Done** / **Готово**, затем **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Либо правый клик по приложению в «Программах» → **Открыть**.

### Windows блокирует exe (SmartScreen)

Нет Authenticode. **Подробнее** → **Выполнить в любом случае**. Это не диагноз вредоносности, а «издатель неизвестен».

### Безопасно ли открывать?

Исходники открыты в этом репозитории (MIT). Приложение не шлёт голос и текст в интернет после установки. Разрешение Gatekeeper / SmartScreen — ваш выбор: вы доверяете сборке с GitHub Releases (или своей сборке из исходников).

У Dictator есть доступ к микрофону и на Mac — к универсальному доступу (для вставки). На Windows вставка — синтезированный Ctrl+V. Уведомления могут показать начало фразы; полный текст остаётся в буфере. Threat model: [SECURITY.md](../SECURITY.md).

### Иконки нет в Dock / на панели задач

Так и задумано. Mac: **правый верхний угол** (строка меню). Windows: **трей**, справа внизу. Если там пусто:

```bash
open /Applications/Dictator.app
```

На Windows откройте меню Пуск → Dictator или снова запустите установленный ярлык.

### Хоткей не работает

Запись можно включить кликом по иконке. На Mac проверьте **Универсальный доступ**. Не используйте `Control + Пробел` — его забирает смена языка.

### Текст есть в буфере, но не вставляется в поле

Mac: нажмите Cmd+V. Добавьте `/Applications/Dictator.app` в **Универсальный доступ**. Запускайте копию из «Программ», не из «Загрузок».

Windows: нажмите Ctrl+V. Не диктуйте в окно, запущенное от имени администратора.

### После обновления на Mac вставка снова сломалась

Подпись бандла изменилась. Удалите Dictator из «Универсального доступа» и добавьте `/Applications/Dictator.app` заново.

### Как проверить, что вставка доверена системе?

Mac: файл `~/Library/Application Support/dictator/last-paste.log`. Нужны `trusted=true` и путь с `/Applications/Dictator.app`.

Windows: `%APPDATA%\dictator\last-paste.log` (путь к exe, без флага Accessibility).

### Intel Mac / Windows ARM / Linux?

Пока нет. Desktop — Apple Silicon и Windows x64.

### На Releases нет zip / exe

Подождите, пока GitHub Actions соберёт релиз после тега, или на Mac [соберите из исходников](BUILD.md).

## Удаление

**Mac**

1. Меню иконки → **Выход**.
2. Перетащите `/Applications/Dictator.app` в Корзину.
3. По желанию удалите настройки: папка `~/Library/Application Support/dictator`.
4. Уберите Dictator из списков микрофона и универсального доступа.
5. Если приложение аварийно завершилось во время распознавания, проверьте временную папку на файлы `dictator-*.wav` и удалите их.

Zip в «Загрузках» после установки не нужен.

**Windows**

1. Меню иконки → **Выход**.
2. **Параметры → Приложения** — удалите Dictator (NSIS).
3. По желанию удалите `%APPDATA%\dictator`.
4. Уберите Dictator из списка микрофона.

Сборка из исходников на Mac: [BUILD.md](BUILD.md). Как устроен Windows-адаптер: [WINDOWS.md](WINDOWS.md).
